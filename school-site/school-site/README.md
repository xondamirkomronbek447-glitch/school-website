# Сайт школы — HTML/CSS/JavaScript

Откройте `index.html` в браузере. Никаких фреймворков не требуется.

## Структура

- `index.html` — разметка страницы
- `style.css` — весь дизайн и адаптивность
- `script.js` — работа кнопок «ПОДРОБНЕЕ» и модальных окон
- `images/school-bg.svg` — локальный фон школы, который можно заменить своей фотографией

## Как заменить фон

Поместите вашу фотографию в `images/`, например `school-photo.jpg`, затем в `style.css` замените:

`url("images/school-bg.svg")`

на:

`url("images/school-photo.jpg")`

## Как изменить информацию

Тексты карточек находятся прямо в `index.html`. Тексты модальных окон находятся в `script.js` в объекте `details`.
